`tt-project`: the worktree sweep (end of run, ttp prune, disk guard) also removes the git worktrees workers leave in finished runs' directories, under the task worktrees' keep rules; the disk alert measures the project's own state/ and worktrees/ per subfolder, names the biggest consumers (run worktrees, task worktrees, state/ subfolders) and gives a partial total as partial, never a bare 0.0 GB; archived big files are write-once and content-addressed (objects/<sha256[:2]>/<sha256>); nothing is placed over an existing archive path, every entry is verified before the worktree loses it, and readers take each entry's own location (old files/<path> manifests still read); the web app's run view lists the archived files again (/api/run/<id> referred to an undefined project).
