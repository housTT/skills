`tt-project`:

- A schedule that starts whole periods late is reported with its missed runs and likely cause; A project pause or a schedule turned off and on again is no schedule gap
- notifier: one alarm when a remote project host stays unreachable for 20 min, one on recovery; notifier: a gap between polls (sleep, stopped notifier) starts a host-down streak anew; an empty registry read keeps host state
- Upstream 'confirmed by quiet' counts the daemon's own running time, not wall time: a host or daemon down stretch no longer counts as quiet
- Status, web and the sweep age a stuck task from when its episode began, not its last update
