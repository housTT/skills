`tt-project`:

- a review that fails check-only (review_failure: check_only) gets no automatic fix and re-review; it stays failed, its dependents stay on it and the coordinator routes the check
- the auto-review spec treats a task whose pr_branch the push remote lacks as a push-branch delivery (push queue on), unless its spec asks for `ttp push --own`
- ttp push --own with no git remote fast-forwards a pr_branch another worktree has checked out in that worktree (merge --ff-only), refused while it has uncommitted changes or the move is not a fast-forward
