Workers get a digest of the charter and memory instead of all of it: the Restrictions verbatim (as before, in their own block), the Goals and Resources whole, only the policies and memory entries meant for workers, and a pointer to the full files, within 8000 characters. A policy tagged `[workers]` or `[coordinator]`, or a memory entry added with `audience`, says who gets it; restrictions in memory always reach workers. On a project with a large charter and memory this cut the worker charter-and-memory block from about 20,000 to under 8,000 characters.
